About This Research
Research Overview

This platform demonstrates a novel integrated approach to Kiswahili audio processing, combining three state-of-the-art NLP models in a unified pipeline.

Models Used
  • ASR: Wav2Vec2 (RareElf/swahili-wav2vec2-asr)
  • Sentiment: DistilBERT Multilingual
  • Summarization: T5-Small
Key Features
  • Automatic chunking for long audio files (>30 seconds)
  • Text segmentation for content exceeding 512 tokens
  • Real-time processing with async pipeline
  • Comprehensive metrics and visualization
